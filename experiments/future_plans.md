# Future Plans — 性能与重建精度提升方向 (2026-08-21)

基于 20k 全量实验后的分析 (数据: heart_pig_stent_with_phase.dcm)。

## 现状基线

| 配置 | PSNR | 耗时 |
|---|---|---|
| 10k, 动态 0.98pct (~16k splats) | 38.90 | ~9min |
| 20k, 600k splats 上限, ROI20+time | 42.78 | 1h56m |
| 20k, 600k splats 上限, ROI40+time | 43.17 | 1h52m |

20k 仍在上升 (42.37→43.17 @ 最后 500 步), 未收敛。

## 数据分析结论

1. **暗边性质 (vignetting 分析)**: 时序中位数帧边缘剖面显示暗边为
   **左上角 collimation 型** (top 0.47x / left 0.59x 中心, 右下 1.4-2x 为
   解剖), 非平滑 vignetting → **保持 ROI 裁剪方案, 不做 flat-field 校正**
   (会过校解剖)。

2. **600k 点云质量 (最终 PLY 统计)**:
   - opacity 84-88% 饱和在 >0.9 (密度被 pin 高, 吸收靠 scale 控制)
   - 12-18% splat scale < 0.05mm (近无用), 存在 100-230mm 超大离群
   - → 大量计算浪费在无效 splat 上; 合理放置的 75-250k 应达到或超过
     600k 的质量, 同时 ~4x 提速。

## 性能方向 (P)

- **P1 densify 阈值甜点扫描** (2026-08-21 完成, 10k iters, ROI20+time,
  卡 1/2/3):
  | 阈值 | splats@10k | PSNR | LPIPS |
  |---|---|---|---|
  | 1e-5 | 75,704 | **40.83** | **0.4268** |
  | 5e-5 | 30,011 (未增长) | 40.38 | 0.4701 |
  | 1e-4 | 29,969 (未增长) | 40.26 | 0.4734 |
  → **1e-5 为甜点**: ~75k splats, 10k 时 PSNR 40.83 (600k 配置同时点仅 ~39),
    LPIPS 0.4268, 且速度快 ~4x (10k ≈ 11min)。5e-5/1e-4 阈值太高几乎不
    densify (停在初始 30k)。

  **P1b + P1c 微调 (2026-08-21 完成, 卡 0/1/2/3)**:
  | 阈值 | iters | splats | PSNR | LPIPS |
  |---|---|---|---|---|
  | 1e-5 @20k | 20000 | 73,237 | 42.72 (best 43.03) | 0.4005 (best 0.3955) |
  | 2e-5 @10k | 10000 | 37,799 | 40.60 | 0.4558 |
  | 3e-5 @10k | 10000 | 30,919 | 40.69 | 0.4687 |
  | 5e-6 @10k | 10000 | 187,936 | 40.81 | 0.4048 |
   → **1e-5 @ 20k 仅 73k splats 达 PSNR 43.03**, 与 600k 配置的 43.17 持平但
     快 ~4x (20k ≈ 32min vs 1h56m)。**LPIPS 随 splat 数提升** (600k: 0.3513
     最好; 1e-5@20k: 0.3955; 5e-6: 0.4048)。甜点 1e-5 (~73k, PSNR/速度最优);
     要更好感知降 5e-6 (~190k)。
- **P2 f16 混合精度**: 参考 dev/f16-mixed 分支, 预期 1.5-2x, 中等风险。
- **P3 eval 瘦身**: LPIPS 只算 2 视图, PSNR/SSIM 全视图 (LPIPS 0.34s/视图,
  每 run ~2min, 占比小)。

## 精度方向 (A)

- **A1 全局刚性 + 局部形变分解** (架构重点): 呼吸主成分为整体垂直平移
  (~2-5mm)。deform 网络加"全局头" — 从 (phase,time) 预测每帧全局平移
  (3 标量), 先刚性移动所有 splat, per-splat 场只学残差。→ 任务变简单,
  更少 splat 同精度, held-out 泛化更好。
- **A2 长训练 + LR 调度**: 20k 未收敛, 30-40k + cosine LR 可能 +1-2dB,
  前提是 P1 提速。
- **A3 HexPlane 分辨率**: rs64→128 / rt32→64 / C16→32 (此前同速 LPIPS
  0.266→0.242), 提速后免费。
- **A4 评估口径**: LPIPS 反转 (noroi 0.304 < roi 0.335) 因评估区域不同
  (516² vs 476²/436²) → eval 统一裁剪后区域, 指标才公平。
- **A5 deform 时间平滑正则**: 相邻时间形变差 L2, 提升 held-out 泛化。

## 执行顺序建议

1. ✅ P1 阈值扫描 → 甜点 1e-5 (~75k splats, 4x 提速)
2. P1b: 1e-5 @ 20k 确认上限 (或扫 2e-5/3e-5 微调)
3. A1 全局刚性头
4. 提速后 A2 (30-40k) + A3 (高分辨率 hexplane)
