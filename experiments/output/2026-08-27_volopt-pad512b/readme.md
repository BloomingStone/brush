# volopt-pad512b — padding 512 + LR 衰减 + 周期体积输出

## 2026-08-27
- 目的: 解决 512² padded 优化的震荡 (mini-batch 过拟合) 与过长训练:
  1) 每步跨弧多样采样 (strided) 2) cosine LR 衰减 1e-4->5e-6 3) 1500 iter
  4) 每 250 存中间体积 (直接评估 volume 重建)。
- 基线: pad512 (无衰减, 3000 iter) 峰值 31.69dB, 震荡 ±1.5dB。

## 结论: DRR 体积优化路线判死刑 (2026-08-27)
- padding 512 虽把 PSNR 推到 ~31.7dB, 但 padded 区域内无任何正确 3D 结构,
  只有奇怪的高频条纹 — 优化器靠这些条纹拟合 2D 图像, 不反映真实解剖。
- 这正是 FDK 有限域问题的延伸: 外围投影信息不足, 反传沿整条射线散射 →
  条纹伪影, 且不收敛到真实结构。
- 判死刑: 放弃 fit_volume DRR 梯度反传体积优化路线。回到 FDK-residual GS。
