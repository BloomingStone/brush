# plane-tv — HexPlane 特征平面空间 TV 扫描

## 2026-08-25 形变场平滑性实验
- commit: 272a768
- 数据: images/pig-data-cor-new-phase.dcm (校正相位)
- 目的: 空间 TV 强制形变场低频/平滑, 验证是否消除高频周期模式 (0.07/mm≈14mm),
  改善冠脉/结构边界模糊
- 配置: 默认 (thr5e-6) + --plane-tv-weight 扫描

## 结果 (2026-08-25, 20k, 新相位数据, thr5e-6)
| 配置 | PSNR | SSIM | LPIPS |
|---|---|---|---|
| baseline (无TV) | 44.14 | 0.9911 | 0.2147 |
| plane-tv 0.001 | 43.90 | 0.9909 | 0.2176 |
| **plane-tv 0.01** | 43.59 | 0.9912 | **0.2097** |
| plane-tv 0.1 | 43.82 | 0.9909 | 0.2185 |
| plane-tv 0.01 + rs32 | 43.64 | 0.9906 | 0.2260 |

## 关键发现: "形变场高频"是导出采样混叠假象 (dump_deform 证实)
- 之前 4.8mm(≈HexPlane 单元) 导出显示相邻差 101%、自相关 -0.3 → 看似高频噪声。
- **dump_deform 加载 ckpt 细采样**: 2.4mm 时 baseline 自相关 0.923, plane-tv 0.960,
  相邻差 6-7% → **形变场本来就是平滑低频的**。混叠因采样间距≈单元且未对齐。
- plane-tv 只是边际更平滑 (0.923→0.960), LPIPS 略好 (0.2147→0.2097) 但 PSNR 略降。
- **修复**: fit_deform 导出改半单元采样 (spacing=cell/2), 见 commit。
